# Ride With Foxy

A mobile-friendly private transportation booking MVP for Las Vegas.

## Included
- No customer login
- One-way, $30 airport one-way, round-trip, hourly, half-day, full-day, and weekend options
- Instant estimate
- One-tap text booking request
- Responsive blue-and-black design
- Private rider PIN and required ride-policy acknowledgement
- Up to 7 passengers in one silver Chevy Traverse
- Clickable OpenStreetMap pickup and destination pins
- Terminal selection for airport rides, with no flight number required

## Booking delivery
Requests open a pre-filled text to Foxy's booking number. They remain unconfirmed until Foxy replies, which prevents the static website from promising two customers the same time slot.

## Publish with GitHub Pages
Open **Settings → Pages**, choose **Deploy from a branch**, select **main / root**, then save.
